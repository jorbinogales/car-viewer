# car-viewer

Showroom 3D del JAC 6 PHEV (React + Three.js) y su video promocional (Remotion).

- `web/`: el showroom. `cd web && npm install && npm run dev` → http://localhost:5173/
- `video/`: video promocional de 20 s. Resultado: [`video/out/promo.mp4`](video/out/promo.mp4). Ver `video/README.md`.
- `blender/`: scripts que separan las piezas y exportan el GLB (`docs/modelo-jac6.md`). Los `.blend` no están en el repo.
- `design/`, `docs/`: especificación de diseño y datos del modelo.
